# 🧮 Práctica 2 – Ejercicios

## 🔹 1. Fundamentos de Arrays

- **Ejercicio 1**: Crear array de 10 números introducidos por teclado. Mostrar índice y valor.
- **Ejercicio 2**: Mostrar todos los elementos de un array separados por espacio.
- **Ejercicio 3**: Mostrar el número más pequeño de un array de 5 elementos.
- **Ejercicio 4**: Array de 100 números del 1 al 100. Calcular suma y media.
- **Ejercicio 5**: Array de tamaño variable con números aleatorios (0–9). Mostrar valores y suma total.

## 🔹 2. Procesamiento con Condiciones

- **Ejercicio 6**: Contar positivos, negativos y ceros en un array de 10 números.
- **Ejercicio 7**: Calcular media de positivos y negativos en un array.
- **Ejercicio 8**: Calcular altura media de N personas y contar cuántas están por encima o debajo de la media.

## 🔹 3. Arrays Combinados y Bidimensionales

- **Ejercicio 9**: Encontrar máximo y mínimo en un array, junto con sus posiciones.
- **Ejercicio 10**: Mostrar nota de un estudiante usando arrays de nombres y notas.
- **Ejercicio 11**: Invertir el orden de un array de tamaño 6.
- **Ejercicio 12**: Calcular letra del DNI usando array de letras y módulo 23.

## 🔹 4. Transición a Listas Dinámicas (`ArrayList`)

- **Ejercicio 13**: Lista de enteros. Pedir números hasta introducir uno negativo. Mostrar suma total.
- **Ejercicio 14**: Lista de nombres. Buscar un nombre y mostrar si existe y su posición.
- **Ejercicio 15**: Eliminar duplicados de una lista de enteros, ordenar y mostrar.
